- 新增四個持有者限定 RPC，更新公開函式清單及拒絕測試。合成資料測試資料夾、停寫 token、JSON 薪資欄位清空、逐檔失敗續傳；原有完整性、PWA、IndexedDB 及響應式測試保留。未授權或操作公司 Drive，未實測 Apps Script/手機。下一批 v0.24.0 安裝及操作手冊；正式 v1.0.0 需實際驗收。

## 操作

以指定資料持有者登入測試環境，進入管理員控制台 → 手動備份與復原中心。更新清單、建立/確認私人備份資料夾（只需一次）。指定月份或控制表可直接備份，仍建議停寫；全部備份先通知同仁、暫停日常寫入，確認進行中寫入及舊入口均停止，再按全部備份。保持頁面開啟，逐檔完成後下載結果、到私人 Drive 檢查每個副本，再手動恢復。逾時/中斷先核對已產生副本，按核對後繼續；如果已重載，報告及 Drive 副本仍在，須人工核對，不能保證自動續接。無法繼續時下載目前結果、核對後重新載入並恢復，不要長期停寫。備份資料夾不得共用；確認父層權限。建議每週及重要更新前備份，依公司可接受遺失期間調整。

JSON 僅核對，請在公司私人設備保存，勿上傳 GitHub。復原演練：先手動建立獨立月檔副本，核對兩份非正式索引檔案 ID，指定正確月份按唯讀比對。結果相符不表示整庫可還原，控制表須在獨立測試環境重新對應所有月檔，禁止覆寫正式資料。詳細驗收參見 ACCEPTANCE_V021.md。
