# WorkPulse v0.4.0 — 月度報表與進階查詢

> 本批已實作及通過模擬測試，**未代表已在公司的 Google Workspace 真正部署**。GitHub Pages 是本機展示資料；公司報表須使用 Apps Script Web App，並經公司管理員驗收權限。

## 介面操作

1. 開啟「統計分析」，預設查詢本月 1 日至今日。可按「本月」「上個月」「近 90 天」，或自行選擇起訖日期。
2. 依員工、部門、專案、工作類型、完成狀態縮小範圍。雲端版變更條件後需要按「查詢報表」，**重新查詢成功前不會下載過期結果**；本機展示版則即時計算。
3. 查看項目數、累計工時、完成率、工作紀錄日期數、專案分布、每日工時、人員統計、部門統計及明細。
4. 點選「CSV 明細」或「Excel 報表」下載；只包含目前篩選結果，並非全公司無限制匯出。

### Excel 報表（真正的 XLSX 格式）

- `統計總覽`：日期範圍、工作項目數、總工時、完成率等。
- `工作明細`：日期、員工、部門、專案、類型、工作項目、內容、成果、狀態、工時、備註、後續工作。
- `人員統計`、`部門統計`、`專案統計`、`每日趨勢`：群組件數／工時／完成率。
- 文件使用 OOXML ZIP、六個工作表、凍結首列、欄位篩選、欄寬與柔和灰藍標題色，不依賴外部 CDN 或瀏覽器下載外掛。
- **公式防護**：所有使用者文字以 `inlineStr` 純文字寫入，不產生 Excel 公式；CSV 另外加上 BOM 與開頭符號防護。請勿將 CSV 當作權威人事或薪資資料。

## 計算口徑

- 項目數＝符合查詢條件的工作明細數，不是日誌筆數。
- 工時＝各項工作自行登錄的投入時數總和，採小數 2 位計算；**不等同薪資、出勤打卡或加班時數**。
- 完成率＝已完成的工作明細數 ÷ 符合條件的工作明細總數。
- 有紀錄日期＝符合條件的不同日期數，不是工作日數。
- 同一天不同員工可有不同紀錄；同一日誌僅取最新 revision 的 Tasks，舊版工作明細不重複納入統計。
- 日期區間為**含首日和末日**，最多 366 天；下載和畫面都使用相同查詢結果。
- 工作明細畫面顯示前 120 筆以控制 DOM 成本，匯出包含查詢成功取得的所有項目。

## 安全與部門權限

- `wpQueryReport(criteria)` 每次由 Apps Script 伺服端取得 `wpContext_()`；用 `Session.getActiveUser().getEmail()` 與員工 allowlist 確認身分。
- `staff` 只能讀自己；`manager` 只能讀自己部門（包含停用員工的歷史資料）；`admin` 可以讀授權管理範圍的全部歷史資料。
- 客戶端無法傳入自己的角色或任意員工 ID 清單；指定不屬於自己查閱範圍的員工／部門會被後端拒絕。
- 試算表 ID、Admin email 與允許網域**只存在 Apps Script 的 Script Properties**；前端及公開 GitHub Pages 不放入憑證。
- 伺服端會檢查起訖日期、狀態／分類以及回傳量；若超過 1,500 份日誌或 10,000 項最新明細，會要求縮小範圍。
- 匯出的 Excel 檔存在本機下載區，屬於公司資料複本。請由公司 IT 規範共享與儲存位置；GitHub 本身不儲存日誌內容。

## 升級與部署

- **維持 schema v3**：v0.4.0 只增加唯讀報表端點與前端，不增加 Sheets 欄位，不必重建資料表，也不需要另外執行遷移函式。
- 部署時以 `npm run gas:build` 重新輸出 `dist-gas/Code.gs` 與 `dist-gas/Index.html`，依 `GOOGLE_SHEETS_DEPLOYMENT.md` 更新 Apps Script 部署版本。
- 既有 v0.2.0 的 schema v2 若尚未遷移，**請先備份並完成 v3 遷移**，不可直接套用這批程式忽略 schema 檢查。
- 驗收至少使用兩個不同部門的員工、主管和管理員各自登入測試篩選；尤其要以修改前端請求參數的方式測試越權拒絕，不能只看下拉選單是否隱藏。
- 測試下載 XLSX 後在 Excel、LibreOffice 或其他試算表程式確認欄位、中文和儲存格文字類型。

## 效能與限制

- 本批適合中小型團隊試用，後端仍須掃描 Sheets 的 `Journals` 和 `Tasks`，不是索引式資料庫；資料持續成長時需要實際測量 Apps Script 執行時間與配額。
- 高量資料可規劃以月份索引、快取、分頁式查詢、或升級為專用資料庫；本批不宣稱具備大型企業資料倉儲效能。
- 尚未完成公司真實 Google Workspace 登入、多人並行和 Sheets 端對端驗收；本地 Node 測試及模擬 `google.script.run` 不代表正式站點已部署。
