# WorkPulse v0.10.0｜會計薪資試算與 Excel 匯出

## 操作

會計在出勤表選擇人員，輸入當次月薪基準，按「開始試算／匯出 Excel」，開啟日期懸浮視窗。預設上一個已完整結束的月份，仍可自行修改起訖日期。確認後讀取該員工對應日期的出勤資料；完成後可匯出專業彩色 Excel。

**日期自動判斷**：使用 JavaScript 本地西元曆，不需要上網查詢或每年快取。2026/12/2 預設 2026/11/1 至 11/30；2027/1/2 預設 2026/12/1 至 12/31；2024/3/2 預設 2024/2/1 至 2/29（閏年）；2025/3/2 預設 2025/2/1 至 2/28。

自訂期間可跨月或跨年，但一次不得超過 366 天，不能選未來日期。期間內尚未登記的日期仍列入每日明細並標示「未登記」，不可解讀為零工時或缺勤。

## Excel 內容

Excel 是在目前瀏覽器直接產生的真正 OOXML 格式，包含字型、灰藍與青綠填色、凍結標題、合併儲存格、欄寬、列印方向、數值格式及公式。

1. 試算總覽：員工姓名、試算起訖日、產出日期、月薪基準、時薪基準、工作及加班時數、已計算加班費、缺少登記筆數、人工核算提醒。
2. 出勤明細：範圍內每個日曆日的日期、星期、出勤日別、上下班、休息分鐘、實際與加班時數、加班費、請假、備註、資料狀態、修訂版本。
3. 計算依據：台灣勞基法平日、休息日與國定假日一般月薪制倍率及適用限制、官方參考網址。

Excel 中總覽 B6 是可調整的月薪基準；Excel 公式可依 B6 重新計算每日加班費及加總。加班費只代表可計算部分，例假及特殊班表必須人工核算。本檔不含所得稅、勞健保、退休金等正式薪資扣除項目。

參考：勞動部加班費試算 https://calcr2.mol.gov.tw/Index

## 資安與部署

網頁只向 Apps Script 傳送員工 ID、開始日期與結束日期，後端 wpAttendanceRange 跨月份讀取 Attendance 工作表；薪資基準與試算金額不會寫入共用 Google Sheets、瀏覽器的 localStorage 或 sessionStorage。試算在目前頁面完成，切換員工、月份或離開出勤頁會清除。

**下載的 Excel 本身有薪資與試算金額**，會計必須依公司保密規範保存、限制分享，不能將它上傳公開資料夾或在共用電腦留下檔案。

若 v0.9.0 曾在真實 Sheets 內儲存過薪資欄位，這些歷史欄位不會在本批自動刪除，須由資料持有者先備份再審核清理。

新 Apps Script 公開與管理員部署包須增加 AttendanceRange.gs；GitHub Pages 的展示版只查本機已有紀錄，無法直接代表公司 Google Drive 已部署。正式上線仍須用公司帳號驗證權限、出勤資料及 Excel 實際開啟情況。
