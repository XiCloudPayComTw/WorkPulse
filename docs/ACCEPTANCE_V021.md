## 2. 分月完整性驗收

先由持有者執行既有停寫程序（至少 10 分鐘只是門檻，須另外確認舊入口及其他寫入均停止）。在私人管理控制台「分月資料完整性驗收」選擇月份，執行唯讀檢查，下載 JSON 留存。異常列位置只供人工核對，不自動更改。先使用 workPulseVerifyMonthFiles 逐批檢查所有月份的表頭及索引。超過上限請人工分批檢查，空月不算通過。舊資料缺少新版請求時不可直接刪除，須確認原始備份與遷移歷史。

## 3. 月檔復原比對（不修改正式資料）

由公司持有者從已驗證的月備份在獨立私人測試資料夾建立一份副本；確認兩檔均不屬任何日常環境，不要選擇正式控制表或正式月檔。管理員控制台 → 手動備份與復原中心 → 指定月份、輸入原始備份及獨立復原副本的試算表 ID → 唯讀比對。確認資料值相符且檢查期間未變，手工抽查各分頁內容。舊版編輯器 workPulseCompareRestoredMonth 仍可用作回退參考，但現行安裝不必另設定三項復原屬性。工具只核對預期欄位的 getValues，不核對公式、格式、父層共用或其他專案索引，不能取代獨立整庫演練；不得把控制表備份直接當正式控制表。獨立測試控制表須人工逐一 remap 至測試月檔後驗收，禁止指向正式資料。

## 4. 回退與上線閘門

發現問題：停止新入口寫入，確認所有執行停止、保留原始待同步與備份，記錄錯誤。核對舊版本與 schema 相容後，在測試環境先驗證，再由公司持有者恢復經核對的部署；不得直接用備份覆寫現行控制表。逐一測試登入、資料讀取與寫入，再恢復。若無相容回退方案，維持停寫並人工處理。所有必要項目實測通過、公司確認風險及交接責任後才能發布正式 v1.0.0。

- 使用現有 Admin TEST 專案及三項屬性即可匯入 unified；此版本尚未部署公司帳號或授權 Drive，未操作真實資料。下一批 v0.23.0 手動備份/復原中心、v0.24.0 精簡安裝及操作手冊、v1.0.0 實際驗收後正式發布。
