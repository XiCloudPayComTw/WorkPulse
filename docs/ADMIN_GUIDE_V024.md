# WorkPulse｜管理員操作及交接手冊

適用 v0.24.0 單一入口。只有指定資料持有者的已驗證 active/effective 帳號可管理，不支援委派管理帳號。一般公司使用者仍採姓名選擇。公司須確認此資料存取政策；若要求每人僅查閱本人資料，先開發個別伺服器端授權。

## 首次使用與日常管理

依 [快速安裝](INSTALL_V024.md) 建立 TEST 及獨立正式環境。登入 → 管理員控制台 → 人員、專案及工作類型，新增測試資料再核對員工入口。停用人員或項目後不應刪除歷史紀錄；停用前確認影響。出勤頁的管理員排班設定與應上班天數應由公司核對；薪資在匯出 Excel 人工處理，勿把薪資寫入系統。管理員能填寫日常工作，但應使用正確人員及日期。

| 頻率（建議） | 操作 |
|---|---|
| 每日 | 查看待處理回報、核對日誌及出勤異常 |
| 每週／重要變更前 | 手動備份並核對私人 Drive 副本 |
| 每月底 | 核對出勤、匯出 Excel、檢查月份及完整性 |
| 每次更新 | TEST 驗收、正式備份、停寫、更新同一部署、復查 |
| 定期及交接前 | 獨立還原演練、核對權限及公司復原方式 |

備份頻率由公司可接受的資料遺失期間決定。無須每日排程；如曾啟用自動排程仍須核對實際觸發器，不會自動移除。

## 手動備份

管理員控制台 → 手動備份與復原中心 → 更新備份清單 → 建立／確認私人備份資料夾。指定月份或控制表可分開備份，建議在無人寫入時執行。全部備份先通知員工暫停正式提交、按「暫停日常寫入」，確認舊部署及進行中的寫入均停止、不要手動修改試算表或管理資料，再按「備份全部資料」。逐檔確認後下載備份結果，於私人 Drive 查閱副本名稱、月份、內容與權限，最後按「恢復日常寫入」。保持頁面開啟；若逾時，確認 Drive 後按「核對後繼續」。關閉頁面不會自動續傳；若無法完成，先下載報告、人工核對後重載並恢復，勿長期停寫。

全部備份涵蓋控制表及當下索引月份，非原子快照。JSON 下載只供人工核對資料值、薪資欄位清空，仍含公司私人資料與 ID，不能直接匯入、不是完整 Drive 副本。獨立復原需先手動複製私人備份，再於復原預檢選月份、輸入兩份非正式索引檔的 ID、按唯讀比對；不得覆寫正式庫。整庫演練另須獨立控制表重新對應所有測試月份。詳見 [備份手冊](BACKUP_V023.md)。

## 維護及故障排除

| 現象 | 處理方式 |
|---|---|
| 無法登入／無法驗證身分 | 確認公司帳號、domain、部署執行身分為主持有者；禁止改 legacy 或匿名 |
| 沒有管理員控制台 | 核對登入帳號是否為 WORKPULSE_ADMIN_EMAIL；禁止共用主持有者密碼 |
| 出現本機展示版 | 停止輸入真實資料，取得正式 /exec；如已有展示資料，先下載移轉封包逐月預檢 |
| 讀取失敗／權限錯誤 | 核對部署版本、控制表 ID、持有者及私人權限；不得重新初始化覆蓋 |
| 儲存結果未確認 | 保留原請求，先查閱正式紀錄，核對後用同 requestId 重送 |
| 版本衝突 | 重新讀取、人工合併、再提交；禁止直接覆蓋 |
| 備份資料夾錯誤 | 核對私人權限及與日常資料夾不同；勿為求成功開放共用 |
| 月份完整性異常 | 暫停寫入、保存副本及唯讀報告；依列位置人工核對，不刪除或改寫歷史 |
| 更新失敗 | 停寫、保留待同步及備份，TEST 確認相容舊版本後回退既有部署 |
| Excel 金額空白 | 在桌面 Excel 依行政規則填寫月薪並重算，確認公式與資料期間 |

正式刪除工作日誌須先停寫至少 10 分鐘，並確認所有寫入停止；使用管理員功能核對紀錄後再執行，刪除是邏輯標記。復原預覽唯讀，若同人同日已有新紀錄不得覆蓋。

## 公司交接（私下保管）

記錄指定持有者、公司管理員與 MFA／帳號復原方式、測試及正式 Apps Script 專案、部署版本及網址、控制表及各資料夾、備份位置與頻率、最近成功備份及還原日期、未完成驗收與風險、程式儲存庫與已驗證發布包、故障處理聯絡人。不得把密碼或 token 放入文件，不公開 ID 或私人網址。由公司管理者控制帳號復原及離職停權；持有者變更不是單改 email，須在隔離環境驗證所有權、部署執行身分、OAuth、資料夾及索引、備份與登入後再切換。不能驗證時維持原持有權與停寫策略，由公司 IT 處理。不得同時讓新舊入口寫入同一資料庫。

交接時確認 [驗收矩陣](ACCEPTANCE_V021.md) 全部必要項目已實測，正式版本須公司簽認。未授權、未測試、無法還原均不能標記已營運。
