# v0.12.0 外勤弱網路與待同步恢復

已載入正式雲端頁面後，連線狀態會在上方更新。瀏覽器 online 只代表網路介面可用，不等於 Google Sheets 可達。工作日誌和出勤正式儲存先保存原始 requestId、expectedRevision 與內容，再呼叫原本 API；離線不發送、逾時或錯誤保留原請求，不自動重送。

切換至原人員即可看見待同步請求，恢復網路後手動重送。已知 CONFLICT 必須先查閱雲端、核對版本，再移除待同步項目及手動重新編輯。移除不會刪除雲端資料。手動重送成功後請重新讀取對應日期並核對；不自動覆蓋未提交草稿。出勤提供捨棄草稿按鈕。

出勤未提交草稿按人員日期存在 sessionStorage，保留原 revision。日誌沿用原草稿機制，離開頁面補做 flush。待同步上限 30 筆，存於當前分頁 sessionStorage（瀏覽器限制時只保留記憶體，顯示警告）。重新整理通常可保留；關閉分頁、清除資料或換裝置可能遺失。無 service worker、離線冷啟動或背景同步。

不暫存薪資及試算金額，不重送管理員寫入或刪除。姓名選單不是身分驗證；共用裝置避免存入機密。後端 schema 與版本檢查不變，未操作公司資料。

測試：模擬後端失敗、手動重送、衝突與草稿隔離；CI 以 PR workflow 為準。真正小尺寸手機與公司 Apps Script 弱網路實機驗收仍待完成。
