# WorkPulse｜員工操作手冊

適用公司已完成驗收的單一入口。向管理員取得正式 /exec 網址並以公司 Google 帳號登入。GitHub Pages 顯示「本機展示版」時不是公司正式資料庫，不要在展示版輸入真實公司紀錄。

## 每日操作

```mermaid
flowchart LR
 A[確認姓名與日期] --> B[填寫工作日誌]
 B --> C[正式儲存]
 C --> D[登記出勤]
 D --> E[正式儲存]
 E --> F[歷史與本月明細核對]
```

| 頁面 | 操作 |
|---|---|
| 工作總覽 | 手機顯示功能首頁，桌面顯示工作摘要 |
| 填寫日誌 | 工作日期、填寫人員、工作類型、專案、工作內容、成果、狀態及工時 |
| 出勤表 | 依人員、月份及日期登記出勤日別、上／下班、休息、請假、備註 |
| 歷史紀錄 | 月份、人員、關鍵字、狀態篩選及快速定位日期 |
| 統計分析 | 桌面依指定期間與條件查詢；手機不提供此頁 |

右上人員選單會維持選擇並同步其他頁面；每次正式儲存前再核對姓名與日期。公司選姓名模式不等於個別權限隔離，請勿以他人姓名填寫或查閱非工作所需資訊。

## 填寫日誌

選工作日期與填寫人員。依實際工作新增項目、選類型與專案，填寫內容及成果，設定已完成／進行中／受阻及工時。一天可有多項工作，總工時不得超過24小時。選填備註及明日工作。可使用「複製上次工作」、「設為常用」及內容建議，帶入後務必確認日期與內容，不會自動提交。卡片可展開／收合。按正式儲存按鈕，等待成功回應，再到歷史紀錄查閱；單純草稿暫存不代表上傳。

## 出勤及 Excel

選人員、月份、日期，輸入日別、上下班時間、休息分鐘、請假及備註。跨午夜下班以隔日計算；「複製前一天上下班時間」只帶時間與休息分鐘，不複製其他欄位。按「儲存出勤紀錄」，查核本月出勤明細。出勤日別、班表、例假與特殊工時仍須依公司規定人工核對。

桌面出勤表可使用「匯出出勤 Excel」：選人員、期間與發薪日 → 查詢與核對出勤 → 下載 Excel。交由行政／會計使用電腦 Excel 核對，月薪在 Excel 填寫，網站不計算或儲存薪資、不自動上傳。手機以日誌與出勤操作為主。

## 查詢與修正

歷史紀錄選月份及人員、搜尋關鍵字、狀態，或用快速定位日期及「前往日期」。展開日期卡片，若同日多位同仁可使用上一頁／下一頁。選「編輯這一天」後核對內容並重新儲存。修改既有紀錄會檢查版本；若其他裝置已更新，先重新讀取並人工比對，不能直接覆蓋。刪除正式日誌須由資料持有者處理。

## 弱網路與手機

草稿自動暫存於瀏覽器，與正式儲存不同；預設分頁暫存可能在關閉時遺失。若公司已設定獨立 offline scope 且你的裝置支援，可在專用設備啟用持久暫存，請先確認不是共用電腦。持久資料未加密，不能保證永遠存在。雲端入口仍需連線驗證，手機加入主畫面只是捷徑，不代表可完全離線開啟。

若顯示尚未同步、儲存結果未確認或網路中斷：保持頁面、先保存原始請求；確認 Google Sheets 已連線後使用「重送原始請求」，不要多次建立新紀錄。版本衝突不可直接重送，請先查閱雲端再請管理員協助。若停寫維護，保留草稿並等待管理員通知恢復。不要清除瀏覽器資料，勿將原始請求或工作內容上傳公開平台。

## 聯絡管理員

紀錄問題時提供日期、人員、頁面、錯誤訊息、裝置與是否已確認正式儲存。截圖遮蔽非必要個資及公司資料；不要提供 Google 密碼、授權碼或私人網址給非授權對象。
