- 基於 PR #29 已合併且完整 CI 通過的 main b09d65ff23e69898e2a6a6f163dc9361888935de，分支 feat/workpulse-v0.19.0-ui-polish；不自動 Merge。
- 沿用灰藍新擬態視覺，集中最後一層色彩、控制元件圓角、次要文字、主要按鈕與焦點輪廓；成功／錯誤通知文字及背景區分。成功訊息 6 秒自動消失，錯誤保留至手動關閉或下一則通知；通知不會在重新渲染後無限延長。沒有更換整套設計或資料格式。

- Chrome 60 路由增加主要內容焦點與底部留白檢查，單元測試底部高度計算。保留 iOS 日期欄位邊界、歷史分頁、IndexedDB 和 PWA。不是完整 WCAG 稽核，實機 iOS/Android、讀屏、低階裝置仍待驗收。
- Google Drive/Sheets 唯一正式雲端，Firebase 取消，未操作公司真實資料或安裝排程。下一階段 v1.0.0 須公司授權、正式部署、備份還原與跨裝置驗收；不因程式完成即宣稱正式營運。
